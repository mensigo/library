## Интро

`property` в Python - это способ повесить на атрибут доп. логику при его чтении/записи/удалении.

Главная цель - сохранить простой API класса и при этом контролировать доступ к данным: валидировать, пересчитывать, ограничивать или делать поле только для чтения.


## Моменты

### 1. Главное назначение property

`property` связывает атрибут с методами:
- getter - что вернуть при чтении
- setter - что делать при присваивании
- deleter - что делать при удалении (опционально)

Внешне это выглядит как обычное поле, но внутри работает код.


### 2. Почему это удобно

**Плюсы в практике:**
- **Инкапсуляция**: прячем внутреннюю реализацию (`_age`, `_price`)
- **Валидация**: не даем положить некорректные данные
- **Обратная совместимость**: можно начать с обычного поля, а позже добавить проверки без изменения внешнего API
- **Читаемость**: обращение к полю остается естественным (`user.age`)


### 3. Когда полезно

- Когда у поля есть ограничения (возраст >= 0, цена > 0, email в нужном формате)
- Когда значение нужно вычислять на лету из других полей
- Когда нужно сделать read-only атрибут (только getter, без setter)
- Когда при изменении значения надо запускать экстра код (нормализация, логирование)


### 4. Пример

```python
class User:
    def __init__(self, age: int):
        self.age = age

    @property
    def age(self) -> int:
        return self._age

    @age.setter
    def age(self, value: int):
        if value < 0:
            raise ValueError("Возраст не может быть отрицательным")
        self._age = value
```

Снаружи это обычное поле (`user.age`), но внутри есть доп. логика / контроль.
